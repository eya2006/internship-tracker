# Internship Tracker

Local web app for tracking internship applications. Data is saved in your browser (`localStorage`).

## Open

Double-click `index.html`, or from this folder:

```powershell
start index.html
```

## Columns

Company, Position, Country, Field, Application Link, Date Applied, Deadline, Status, Contact, Follow-up Date, Interview, Result, Notes.

## Statuses

🔎 To Apply · 📝 Preparing · 📤 Applied · 📩 Follow-up · 🎤 Interview · ⏳ Waiting · ✅ Accepted · ❌ Rejected · 🚫 Withdrawn
